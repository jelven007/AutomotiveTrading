# 安全设计与威胁模型

> 文档编号：QT-SEC-001
>
> 版本：1.1-draft

## 1. 保护资产

- 用户身份和 MFA。
- 租户业务数据。
- 模型 API Key。
- 券商凭据与交易解锁信息。
- 币安 API Key、Ed25519/RSA 私钥和 HMAC Secret。
- 策略源码和参数。
- 行情、资讯和授权数据。
- 订单、成交、持仓、资金和账本。
- 模型输入输出与审计日志。

## 2. 信任边界

1. 浏览器与公网 Gateway。
2. Gateway 与业务服务。
3. 业务服务与模型供应商。
4. Trading 与 Broker Connector。
5. Connector 与券商网关。
6. Backtest Scheduler 与不可信 Python Runner。
7. 租户 A 与租户 B。

## 3. 主要威胁与控制

| 威胁 | 控制 |
| --- | --- |
| 跨租户 IDOR | Token 租户上下文、服务校验、复合索引、自动化越权测试 |
| 密钥泄漏 | KMS、不可回显、日志脱敏、最小权限、轮换 |
| 自定义 Base URL SSRF | URL 校验、DNS/IP 复核、出口代理、目标白名单 |
| 提示词注入 | 外部文本隔离、无工具权限、输出 Schema、确定性风控 |
| Python 沙箱逃逸 | 非特权容器、Seccomp、只读文件系统、NetworkPolicy |
| 重复下单 | 幂等键、提交账本、券商查询、状态机 |
| 伪造订单回报 | mTLS/签名、来源校验、Broker ID 去重、对账 |
| 币安 API Key 被滥用 | KMS、固定出口 IP、禁止提现权限、权限分离、轮换和告警 |
| 合约参数混淆 | 帐号 Scope、持仓模式、保证金模式和 `reduceOnly` 强校验 |
| 杠杆强平 | 风险率监控、预强平保护模式、禁止扩大风险、人工值守 |
| 签名重放或时钟偏差 | 小 `recvWindow`、服务器时间同步、Nonce/幂等账本 |
| 管理员滥用 | MFA、双人审批、审计和告警 |
| 供应链攻击 | 锁定依赖、SBOM、镜像签名和漏洞扫描 |
| 审计篡改 | 追加写入、哈希链、独立权限和归档 |

## 4. 模型配置安全

- 只有租户管理员拥有写权限。
- Key 只在 HTTPS 请求体中短暂进入后端。
- 后端立即写入 KMS，业务库仅保存 Secret ID。
- Key 不返回前端，不进入消息、日志、Trace 和错误详情。
- 连接测试使用固定无敏感 Prompt。
- 自定义 Base URL 默认只能访问公网 HTTPS。
- 解析 DNS 后阻止 Loopback、Link-local、私网和云元数据地址。
- 若未来允许租户内网模型，必须通过专用 Agent/VPN，不直接放开 SSRF 限制。

## 5. 交易安全

- 自动实盘默认关闭。
- 高风险操作要求近期 MFA。
- 下单签名包含账户、标的、方向、数量、价格和幂等键。
- 网络超时不得自动重试。
- 风控服务异常时拒绝交易。
- Connector 失联时进入只读或保护模式。
- 支持平台、券商、租户、账户和策略急停。
- 订单与成交通过对账校验外部事实。
- 币安 Key 优先使用 Ed25519；兼容 HMAC/RSA 时采用同等 KMS 和轮换策略。
- 查询与交易使用最小权限，具有提现权限的 Key 一律拒绝。
- 币安 Connector 使用固定出口 IP，生产 Key 必须配置 IP 白名单。
- 币安现货、全仓杠杆、逐仓杠杆和 U 本位永续使用独立帐号 Scope。
- 借款、还款、划转、提高杠杆和启用生产写权限必须 MFA 并审计。
- 全仓/逐仓达到预警阈值或合约接近强平时进入保护模式，只允许降低风险。
- 币安网络超时后订单进入 `unknown`，必须查询确认，禁止盲目重试。

## 6. 数据与隐私

- 数据分类：公开、内部、敏感、严格敏感。
- 券商凭据和个人身份属于严格敏感。
- 币安 API Key、私钥/Secret、账户 UID 和完整资产明细属于严格敏感。
- 模型输入默认不包含用户身份证、手机号、完整券商账号。
- 导出使用短期签名链接并审计。
- 跨境模型调用必须在租户配置和法律评审允许范围内。
- 数据删除不影响依法必须保留的交易和审计记录。

## 7. 安全验收

- 威胁建模评审。
- SAST、SCA、镜像和 IaC 扫描。
- API 与 Web 渗透测试。
- 租户隔离专项测试。
- Python 沙箱逃逸测试。
- 密钥泄漏扫描。
- 自动实盘红队演练。
- Critical/High 问题全部关闭或由负责人书面接受。
