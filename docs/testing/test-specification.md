# 测试规格说明书

> 文档编号：QT-TS-001
>
> 版本：1.1-draft

## 1. 测试目标

验证系统满足 SRS，重点证明：

- 多租户数据不越权。
- 大模型配置安全且调用受控。
- 模型结果不能绕过组合协调与风控。
- 交易订单不重复、不丢失、可对账。
- 币安现货、全仓/逐仓杠杆和 U 本位永续不会跨 Scope 混用资产或订单。
- 杠杆和合约风险状态只能触发风险降低操作，不能扩大敞口。
- Python 策略无法突破沙箱。
- 外部服务故障时系统安全降级。

| 测试层 | 范围 |
| --- | --- |
| 单元 | 领域规则、计算、状态机、Schema |

| 安全 | 身份、租户、密钥、代码沙箱、提示词注入 |
| 可靠性 | 重复、延迟、断连、重启、消息和数据库故障 |
| 灾备 | 备份恢复、跨可用区和事件重放 |

## 4. 测试数据

- 三个租户，每个租户至少五类角色。
- A 股、港股、美股各不少于 20 个标的。
- 币安现货、全仓杠杆、逐仓杠杆和 U 本位永续各准备代表性交易对。
- 杠杆数据包含资产、负债、利息、风险率、借款库存不足和强平状态。
- 合约数据包含单向/双向持仓、全仓/逐仓保证金、杠杆、标记价格、
  强平价、资金费率和 ADL 风险。
- 包含停牌、退市、不同手数、跨币种和错误代码映射。
- 包含正常、延迟、缺失、重复和乱序行情。
- 包含模型正常、非法 JSON、超时、限流和注入响应。
- 包含订单全状态、部分成交、撤单冲突和未知状态。
- 敏感数据使用不可逆脱敏或人工合成。

## 5. 入口和退出标准

### 5.1 入口

- 需求已基线化。
- 接口和数据 Schema 已版本化。
- 测试环境可部署。
- 关键 Stub 可控制故障。
- 外部测试账号已准备，或批准使用 Stub。

### 5.2 退出

- P0/P1 用例 100% 通过。
- P2 用例通过率不低于 98%，无未接受高风险缺陷。
- 无未关闭 Critical/High 安全问题。
- 性能满足 NFR。
- 备份恢复和灾备演练通过。
- 实盘灰度满足连续观察期。

## 6. 测试方法

### 6.1 状态机

对策略生命周期和订单状态机进行：

- 合法转移测试。
- 非法转移拒绝测试。
- 并发转移测试。
- 重复事件测试。
- 服务重启恢复测试。

### 6.2 属性测试

持续生成随机订单和成交序列，验证：

- 资金和可卖数量不为负。
- 成交数量不超过委托数量。
- 撤单终态不可再次成交，除非外部事实证明在先成交。
- 同一券商成交只入账一次。
- 账本借贷平衡。

### 6.3 故障注入

- 模型超时、429、5xx 和非法响应。
- 行情延迟、断流和乱序。
- Kafka 重复、延迟和消费者重启。
- MySQL 主从切换。
- Redis 丢失非持久缓存。
- Connector 断连和下单超时。
- 币安时间偏差、签名失败、限频、User Data Stream 过期和事件乱序。
- 币安借还款待处理、库存不足、预强平、强平和合约 ADL 风险。
- Audit 暂时不可用。

## 7. 性能基线

| 场景 | 指标 |
| --- | --- |
| 常规查询 | P95 <= 500 ms |
| 平台风控 | P95 <= 300 ms |
| 行情触发入队 | P95 <= 1 s |
| WebSocket | 目标连接数由容量计划确定，零跨租户推送 |
| 订单事件 | 已确认事件零丢失 |

压测报告必须记录版本、数据量、资源配置、错误率和瓶颈。

## 8. 安全测试

- OWASP ASVS/API Top 10。
- IDOR 与租户越权。
- Token 重放、会话撤销和 MFA 绕过。
- API Key 回显、日志泄漏和权限提升。
- 币安提现权限 Key 拒绝、固定出口 IP 白名单和 Ed25519 私钥保护。
- 现货、杠杆和合约 Scope 越权与参数混淆。
- SSRF，尤其是自定义 Base URL。
- 提示词注入和数据外泄。
- Python 文件、进程、网络和资源逃逸。
- 镜像、依赖和供应链扫描。

自定义模型 Base URL 必须阻止访问云元数据、Loopback、Link-local 和未批准内网。
币安生产 Key 必须验证最小权限和 IP 白名单；测试记录不得保存完整 Key、
Secret、私钥、UID 或资产明细。

## 9. 缺陷分级

| 级别 | 定义 |
| --- | --- |
| Critical | 资金损失、重复下单、跨租户泄漏、密钥泄漏、沙箱逃逸 |
| High | 风控绕过、账实不符、无法撤单、重大数据错误 |
| Medium | 重要功能异常但有替代路径 |
| Low | 轻微交互、文案或低风险兼容问题 |
