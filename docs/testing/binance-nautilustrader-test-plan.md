# 币安 NautilusTrader 专项测试计划

> 文档编号：QT-TP-BIN-NT-001
>
> 版本：2.0
>
> 日期：2026-09-21
>
> 状态：已确认，待执行

## 1. 目标

验证 `QT-REQ-BIN-NT-001` 2.0 和 `QT-DES-BIN-SIMPLE-001`：

- 每个用户只能安全绑定一个币安账号。
- 重新绑定成功时覆盖，失败时保留旧账号。
- 阶段一只查询权限、现货余额、U 本位余额和持仓。
- Spot 与 USD-M 查询可以局部降级。
- 阶段二的人工交易写操作具备 MFA、幂等和不确定结果保护。
- 凭据不会以明文进入数据库、响应、日志、Trace 或浏览器残留。

## 2. 测试层级

| 层级 | 环境 | 外部依赖 | 目标 |
| --- | --- | --- | --- |
| 单元 | Local/CI | Fake Runtime、SQLite/MySQL | 单账号、替换、缓存、幂等 |
| 组件 | Local/CI | Nautilus 公共对象 | 配置、快照和订单映射 |
| 集成 | Binance Testnet | Spot、USD-M | 查询和交易契约 |
| E2E | Integration | Web、Trading、MySQL | 用户完整流程 |
| 生产灰度 | Production | 真实账号 | 只读后小额人工交易 |

真实凭据、完整资产和持仓明细不得进入 CI、报告或截图。

## 3. 阶段一单元测试

### TC-BIN-NT-001 本地主密钥

- 使用权限为 `600` 的 32 字节主密钥启动。
- 分别使用缺失文件、目录、符号链接和宽松权限启动。
- 预期：合法文件正常加载；异常配置 Fail Closed。

### TC-BIN-NT-002 凭据加密

- 相同凭据加密两次。
- 预期：nonce 和密文不同，均可解密。
- 修改密文、nonce、账号 ID 或算法版本。
- 预期：认证失败，不返回部分明文。

### TC-BIN-NT-003 单账号约束

- 同一用户连续绑定两次。
- 预期：账号记录数始终为一，第二次覆盖第一次。
- 两个不同用户分别绑定。
- 预期：各自只有一条记录，数据隔离。

### TC-BIN-NT-004 重新绑定回滚

分别注入权限探测失败、候选 Runtime 启动失败、Spot 查询失败、USD-M 查询失败和
数据库提交失败。

预期：

- 旧账号记录和密文保持不变。
- 旧 Runtime 继续可用。
- 候选 Runtime 被停止。
- 新凭据不出现在日志和异常中。

### TC-BIN-NT-005 权限准入

覆盖：

- 无读取权限。
- 未启用 IP 限制。
- 开启提现。
- 开启内部划转。
- 开启通用划转。
- 合法只读 Key。
- 合法且具备阶段二交易权限的 Key。

预期：前五类拒绝绑定；后两类允许绑定并正确展示权限。

### TC-BIN-NT-006 进程内快照

- 5 秒内连续查询两次。
- 预期：第二次复用快照。
- 使用 `refresh=true` 查询。
- 预期：绕过快照并重新读取。
- 验证查询前后数据库无余额或持仓写入。

### TC-BIN-NT-007 产品局部降级

- Spot 失败、USD-M 成功。
- USD-M 失败、Spot 成功。
- 权限失败但 Runtime 快照仍存在。

预期：响应按区域返回 `ok|error`，成功区域不被失败区域覆盖。

## 4. Nautilus 组件测试

### TC-BIN-NT-020 客户端配置

- Spot 使用 `BinanceAccountType.SPOT` 和 `BINANCE_SPOT`。
- U 本位使用 `BinanceAccountType.USDT_FUTURES` 和 `BINANCE_FUTURES`。
- Testnet 与生产环境不得混用。
- 运行时只接受一组 HMAC 凭据。

### TC-BIN-NT-021 账户快照映射

- Spot 零余额被过滤，非零余额保留。
- U 本位余额字段精度不丢失。
- U 本位零持仓被过滤，非零持仓保留方向、数量、入场价、标记价和未实现盈亏。
- 每个区域包含来源时间和新鲜度。

### TC-BIN-NT-022 Runtime 生命周期

- 无账号时服务健康，但返回未绑定。
- 服务启动后加载唯一账号。
- 候选 Runtime 验证成功后替换旧 Runtime。
- 停止后清除凭据引用。
- Spot 与 USD-M 状态分别维护。

## 5. 阶段一 API 与 Web

### TC-BIN-NT-030 登录门禁

- 未登录访问币安页面和 API。
- 预期：页面进入登录，API 返回 401。

### TC-BIN-NT-031 首次绑定

- 输入别名、HMAC Key、Secret 并确认固定出口 IP。
- 预期：绑定成功；敏感字段离开 DOM；页面显示账号摘要和三类查询数据。

### TC-BIN-NT-032 表单最小化

- 打开绑定弹窗。
- 预期：只有别名、API Key、API Secret 和 IP 确认。
- 预期：不存在凭据类型、Scope、MFA、产品和交易权限选择。

### TC-BIN-NT-033 重新绑定

- 使用有效新凭据重新绑定。
- 预期：页面只保留一个账号，新指纹和数据生效。
- 使用无效新凭据重新绑定。
- 预期：显示错误，旧账号仍可刷新。

### TC-BIN-NT-034 聚合查询

- 打开“现货资产”“U 本位”“API 权限”三个标签。
- 预期：数据类型正确，无订单、交易或账号切换控件。

### TC-BIN-NT-035 局部错误展示

- 注入 Spot 或 USD-M 单侧错误。
- 预期：仅对应标签显示错误，其余标签仍可操作。

### TC-BIN-NT-036 删除账号

- 删除当前账号。
- 预期：Runtime 停止，账号和密文删除，页面恢复未绑定状态。

## 6. 阶段一真实只读验收

运行前必须显式设置生产只读凭据，测试工具不得输出其值。

1. 验证 API 权限与币安控制台一致。
2. 验证现货非零余额与币安页面一致。
3. 验证 U 本位余额与币安页面一致。
4. 验证 U 本位非零持仓与币安页面一致。
5. 连续刷新并确认无重复 Runtime、无后台任务、无数据库快照。
6. 分别阻断 Spot 和 USD-M，确认局部降级。

## 7. 阶段二单元与组件测试

### TC-BIN-NT-040 MFA 交易会话

- 未验证、已验证、过期和用户不匹配的交易会话分别调用写接口。
- 预期：只有当前用户未过期会话通过。
- 绑定和查询始终不要求 MFA。

### TC-BIN-NT-041 订单映射

覆盖：

- Spot 市价、限价。
- USD-M 市价、限价。
- GTC 限价单。
- 非法数量、价格和最小名义金额。
- 条件单和自动策略来源。

预期：支持范围正确映射；非目标请求在调用 Nautilus 前拒绝。

### TC-BIN-NT-042 订单幂等

- 并发提交 20 个相同幂等键和相同请求。
- 预期：只有一次 Nautilus 提交。
- 相同幂等键配不同请求。
- 预期：返回 `idempotency.conflict`。

### TC-BIN-NT-043 撤单幂等

- 对同一订单并发发起相同撤单请求。
- 预期：只调用 Nautilus 一次，返回同一结果。

### TC-BIN-NT-044 U 本位设置

- 设置允许范围内杠杆。
- 设置 `cross|isolated`。
- 重复设置相同值。
- 输入超范围杠杆、双向持仓或未知 symbol。

预期：合法请求幂等成功，非法请求不调用 Nautilus。

### TC-BIN-NT-045 不确定结果

- 模拟交易所已经接受请求，但本地收到超时或断连。
- 预期：记录 `pending_reconciliation`，不自动重发。

### TC-BIN-NT-046 写入门禁

分别模拟：

- `LIVE_TRADING_ENABLED=false`。
- Nautilus 未就绪。
- 私有状态过期。
- 启动对账未完成。
- 缺少对应交易权限。

预期：写请求被拒绝，查询能力不受影响。

### TC-BIN-NT-050 Spot 生命周期

1. 查询现货余额。
2. 提交远离盘口的限价单。
3. 查询订单。
4. 单笔撤单。

6. 核对订单和成交。

### TC-BIN-NT-051 USD-M 生命周期

1. 查询余额和持仓。
2. 设置低杠杆和逐仓模式。
3. 提交最小允许限价单并撤单。
4. 提交最小允许市价单。
5. 核对订单、成交、余额和持仓。

### TC-BIN-NT-052 重启与断线

- 在订单存在时重启 Trading Service。
- 在提交后中断私有流。
- 预期：未决状态可核对，不重复提交。

## 9. 故障注入

| 故障 | 阶段一期望 | 阶段二附加期望 |
| --- | --- | --- |
| DNS 失败 | 对应区域错误 | 禁止对应产品写入 |
| TLS 握手失败 | 返回稳定错误码 | 不盲目重试 |
| REST 429/418 | 提示稍后刷新 | 写请求不自动重发 |
| 主密钥损坏 | 账号不可解密 | 所有写请求关闭 |
| MySQL 短时失败 | 旧账号不被覆盖 | 不确认未持久化订单 |
| Spot 断线 | USD-M 可查询 | Spot 写入关闭 |
| USD-M 断线 | Spot 可查询 | USD-M 写入关闭 |
| 下单响应丢失 | 不适用 | `pending_reconciliation` |

## 10. 安全测试

- API Key、Secret、密文和 nonce 回显扫描。
- 日志、异常、Trace 和浏览器缓存泄漏扫描。
- 主密钥文件权限和只读挂载检查。
- 跨用户 IDOR 和密文交换。
- 绑定接口无需 MFA，但必须登录并满足账号管理权限。
- 阶段二全部写接口检查 MFA 和 `Idempotency-Key`。
- 确认不存在提现、划转、现货杠杆和自动策略接口。

## 11. 性能与稳定性

| 场景 | 门槛 |
| --- | --- |
| 5 秒内快照查询 | P95 <= 500 ms |
| 强制刷新 | 网络正常时 P95 <= 3 s |
| 单侧失败返回 | P95 <= 5 s |
| Runtime 替换 | 30 s 内完成或明确失败 |
| 阶段二幂等判断 | P95 <= 50 ms |
| 连续运行 | 24 小时无重复 Runtime 或凭据泄漏 |
